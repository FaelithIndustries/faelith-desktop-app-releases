# Faelith Desktop - Releases

This repository only hosts installers and the auto-update feed (`latest.json`). Source code is not published here.

## Download

Get `Faelith_<version>_x64-setup.exe` (recommended) or the `.msi` from [Releases](https://github.com/FaelithIndustries/faelith-desktop-app-releases/releases/latest).

## Updates

The app checks this repository's latest release automatically. When a new version exists, an **Update** button appears in the sidebar (and in the IDE header). Updates are signed and verified before installing.
